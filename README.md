# Horii Overlay

Live Hypixel/BedWars stats overlay. MVP monorepo with Next.js web app, Fastify API/WebSocket hub, shared Zod protocol, provider abstraction, PostgreSQL/Redis local services, and Forge 1.8.9 client bridge.

## Development

```bash
npm install
npm run test
npm run typecheck
npm run build
```

See `docs/architecture.md`, `docs/protocol.md`, and `docs/deployment.md`.
